# Trovix POS: releases

This repository only hosts the **Releases** of the Trovix POS desktop app. Installed copies of Trovix check
[Releases](https://github.com/itsmohitkr/pos-inventory-application/releases) for updates, so this repository
and its releases stay in place.

Development has moved to a private repository. The source code that used to live here remains in this
repository's history, but it is no longer updated.

**Download Trovix:** get the latest installer from the
[latest release](https://github.com/itsmohitkr/pos-inventory-application/releases/latest).

**Support:** support@trovix.app
